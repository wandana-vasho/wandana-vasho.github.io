# wandana-vasho.github.io

My GitHub Pages landing page.

**Live:** https://wandana-vasho.github.io/

## About

This is a minimal personal landing page hosted at my default GitHub Pages address. My full portfolio — with real project details, work experience, skills, and a working contact form — lives at [wandana-vasho.vercel.app](https://wandana-vasho.vercel.app/); that's the link I actually share with recruiters and on LinkedIn.

## What's here

A single static page: name, and a simple dark theme. No backend, no build tools — just one HTML file with inline CSS.

## Notes

This site sat with a stuck GitHub Actions build for a while (the deployment stayed queued and never actually ran) before getting resolved by resetting the Pages source in repo settings. Worth remembering if a future GitHub Pages deploy ever gets stuck the same way.

## Stack

Plain HTML/CSS, no dependencies, no build step. Deployed via GitHub Pages, source: `main` branch, root folder.
